# Curated opportunity inputs (`pipeline_grants/data/`)

Drop hand-curated funding-opportunity lists here as CSV. A `wcm_curated` ingest
adapter (parallel to `grants_gov.py`) reads them, maps each row to an
`Opportunity` (`models.py`), and runs them through the **same** normalize → denoise
→ score → persist path as Grants.gov. They land as `GRANT#` DynamoDB items in the
`reciterai` table and are indistinguishable from API-sourced opportunities
downstream (SPS GrantRecs).

## File to add

```
pipeline_grants/data/wcm_curated_opportunities.csv
```

One row per opportunity. UTF-8, header row required.

## Columns

`opportunity_id` is built as `wcm_curated:<source_id>`, so provide a stable
`source_id` per row.

| Column | Required | Maps to `Opportunity` | Notes |
|---|---|---|---|
| `source_id` | ✅ | `source_id` | stable unique id (any WCM key); → `opportunity_id = wcm_curated:<source_id>` |
| `title` | ✅ | `title` | SPS drops the record if blank |
| `synopsis` | ✅ | `synopsis` | **descriptive abstract** — the scorer reads `title`+`synopsis` to build the topic vector. A bare name/URL won't match anyone. |
| `sponsor` | — | `sponsor` | e.g. funder name |
| `source_url` | — | `source_url` | canonical opportunity page |
| `mechanism` | — | `mechanism` | e.g. `R01`, internal pilot |
| `program_type` | — | `program_type` | optional |
| `status` | — | `status` | e.g. `open`, `forecasted` |
| `open_date` | — | `open_date` | ISO `YYYY-MM-DD` |
| `due_date` | — | `due_date` | ISO `YYYY-MM-DD`; blank = continuous |
| `eligibility_raw` | — | `eligibility_raw` | natural-language prose; SPS derives eligibility flags from it — do not pre-structure |
| `cfda_list` | — | `cfda_list` | `;`-separated CFDA numbers |
| `award_ceiling` / `award_floor` / `estimated_funding` | — | same | integers (USD) |
| `number_of_awards` | — | `number_of_awards` | integer |

Topic vector (`topic_vector`) and career-stage appeal (`appeal_by_stage`) are
generated by the pipeline (production scorer + Stage-B LLM judge) — do **not**
include them in the CSV.

## After the CSV is added

1. Build/run the `wcm_curated` ingest (writes `GRANT#` items to the `reciterai`
   table — run with **SPS-staging** credentials, account `665083158573`, first).
2. SPS operator: `npm run etl:dynamodb` then `npm run search:index`.
3. Verify in `/edit/find-researchers` with a real `wcm_curated:<id>`.
