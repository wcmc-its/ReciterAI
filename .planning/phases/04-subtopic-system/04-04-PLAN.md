CLI: `python generate_see_also.py --input <hierarchy.json> --output <see_also.json> [--temperature 0.0]`

Algorithm:
1. Load input JSON, validate top-level `topics` key present.
2. Count parent topics; if <2, write empty `{"see_also": [], "pre_filter_count": 0, "post_filter_count": 0}` and exit 0.
3. Build Sonnet user message via `BUILD_SEE_ALSO_USER_MESSAGE`.
4. Call `bedrock_converse(SONNET_MODEL, SEE_ALSO_SYSTEM_PROMPT, user_msg, temperature=<arg>, max_tokens=8192)`. Strip JSON fences.
5. Parse response `{"links": [...]}`.
6. Apply `_apply_bidirectionality_filter(links)`:
   - Build adjacency set: `adj = {(l["from"], l["to"]) for l in links if l["from"] != l["to"]}`
   - Keep: `[l for l in links if l["from"] != l["to"] and (l["to"], l["from"]) in adj]`
   - Deduplicate by `(from, to)` tuple.
7. Write output JSON per schema shown in `<interfaces>`, including `generated_at` ISO UTC, `temperature`, `pre_filter_count` (Sonnet-proposed), `post_filter_count` (after filter), `sonnet_model_id`.
8. Log: proposed N, retained M, dropped (non-bidirectional) K, dropped self-loop S.
