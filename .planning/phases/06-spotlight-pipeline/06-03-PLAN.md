<objective>
Implement the rotation selector and the SPOTLIGHT_HISTORY# write path. Reads the top-50 PoolEntry list (from Plan 06-02) plus per-subtopic last-shown state from DynamoDB; computes `selection_score = pool_score × (1 - exp(-weeks_since_last_shown / 12))` (τ = 12 weeks per CONTEXT decision Q1.3); greedily picks 10 subtopics enforcing one-per-parent-topic diversity. Also implements the post-publish UpdateItem that writes back `last_shown_at`, `shown_count`, and `last_shown_publish_id` so the next publish run sees fresh state.

Purpose: SPOT-03 (rotation selector with exponential decay + parent diversity) + SPOT-04 (last-shown state queryable by subtopic_id in DynamoDB). Cold-start (never-shown subtopics) gets multiplier 1.0 (full pool_score) — the formula handles this naturally via `math.inf` arithmetic.

Output: two `spotlight/` modules + dedicated pytest suite. Mocks DynamoDB; zero AWS calls in tests.
