**Phase 1 -- Extract synopses and batch-process topic clusters:**

Function `extract_synopses() -> list[str]`:
- Connect to ReciterDB using `get_db_connection()`
- Execute `SYNOPSIS_EXTRACTION_SQL` to get all synopses
- Return list of synopsis strings (filter out None/empty)
- Print count: "Extracted {N} synopses from ReciterDB"

Function `make_batch_prompt(synopses: list[str]) -> str`:
- Use the exact prompt from RESEARCH.md Code Examples "Taxonomy Generation Prompt (Batch Pass)"
- Input: list of synopses for this batch
- Ask for 8-12 mid-level research topic clusters
- Request JSON format: `{"topics": [{"id": "snake_case_id", "label": "Human Readable Label", "description": "2-3 sentence description"}]}`

Function `extract_topic_clusters(client: BedrockClient, synopses: list[str], batch_size: int = 75) -> list[dict]`:
- Split synopses into chunks of `batch_size` (default 75 per D-05 and RESEARCH.md Pattern 9)
- For each chunk, call `client.call_json(model=SONNET_MODEL, messages=[{"role": "user", "content": make_batch_prompt(chunk)}])`
- Collect all returned topic dicts into a flat list
- Print progress: "Batch {i}/{total}: extracted {N} topics"
- Return all raw topics

**Phase 2 -- Consolidate into ~50 final topics:**

Function `make_consolidation_prompt(raw_topics: list[dict], target_count: int = 50) -> str`:
- Use the exact prompt from RESEARCH.md Code Examples "Taxonomy Consolidation Prompt (Final Pass)"
- Include all raw topics as JSON
- Request exactly `target_count` final topics
- Request JSON: `{"taxonomy_version": "taxonomy_v1", "topics": [{"id": "...", "label": "...", "description": "..."}]}`

Function `consolidate_taxonomy(client: BedrockClient, raw_topics: list[dict]) -> dict`:
- Call `client.call_json(model=SONNET_MODEL, messages=[{"role": "user", "content": make_consolidation_prompt(raw_topics)}])`
- Validate response has `taxonomy_version` and `topics` keys
- Validate topic count is between 40-60 (warn if outside this range)
- Return the full taxonomy dict

**Phase 3 -- Automated validation (D-08):**

Constant `VALIDATION_QUERIES`: Use the exact 12 sample queries from RESEARCH.md Code Examples "Validation Sample Queries".

Function `make_validation_prompt(query: str, taxonomy: dict) -> str`:
- Give Sonnet the query and full taxonomy
- Ask: "Which topics from this taxonomy would be relevant to answer this query? Return JSON: {\"matched_topics\": [{\"id\": \"topic_id\", \"relevance\": \"high/medium/low\", \"reason\": \"brief explanation\"}]}"

Function `validate_taxonomy(client: BedrockClient, taxonomy: dict) -> dict`:
- For each query in VALIDATION_QUERIES, call `client.call_json(model=SONNET_MODEL, messages=[{"role": "user", "content": make_validation_prompt(query, taxonomy)}])`
- Print each query and its matched topics with relevance
- Count queries with at least 1 high-relevance match
- Return summary: `{"total_queries": N, "queries_with_match": M, "match_rate": M/N, "details": [...]}`

**Main function `main()`:**
- Parse optional `--batch-size` arg (default 75)
- Parse optional `--skip-extraction` flag (use cached synopses from a local file)
- Run Phase 1 (extract + batch cluster extraction)
- Run Phase 2 (consolidation)
- Run Phase 3 (validation)
- Print validation summary with match rate
- If match_rate < 0.8, print WARNING: "Taxonomy may need revision -- only {match_rate*100}% of sample queries had a high-relevance match"
- Write taxonomy to `taxonomy_v1.json` with `json.dump(taxonomy, f, indent=2)`
- Print: "Taxonomy written to taxonomy_v1.json -- REVIEW BEFORE RUNNING score_publications.py (per D-07)"

**Entry point:**
```python
if __name__ == "__main__":
    main()
```
