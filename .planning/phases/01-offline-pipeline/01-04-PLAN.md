DynamoDB record type schemas (from RESEARCH.md):
- TOPIC#: PK=`TOPIC#<topic_id>`, SK=`SCORE#NNNN#ACTIVITY#pmid_<pmid>`, attrs: faculty_uid, score, synopsis, impact_score, year, journal, title, topic_scores_version
- FACULTY#: PK=`FACULTY#cwid_<cwid>`, SK=`PROFILE`, attrs: name, department, title, h_index, article_count, first_author_count, last_author_count, top_topics
- TOOL#: PK=`TOOL#<tool_id>`, SK=`SCORE#NNNN#ACTIVITY#pmid_<pmid>`, same attrs as TOPIC#
- DEEPDIVE#: PK=`DEEPDIVE#<domain>`, SK=`META`, attrs: domain, generated_at, taxonomy_version, subtopics, content, reviewed_by, review_status

reciterai_keyword_relevance schema (verified from ReciterAI/schema/00_unified_schema.sql):
- entity_type: enum('publication','grant','clinical_trial','patent')
- entity_id: varchar(255) -- internal numeric entity ID
- external_id: varchar(50) -- PMID for publications
- keyword: varchar(255) -- the tool/keyword name (becomes tool_id)
- relevanceScore: int(11) -- 0-100 scale (divide by 100.0 for normalized 0.0-1.0)

**Record Type 1 -- TOPIC# score records (DB-02):**

Function `build_topic_records(scoring_results: list[dict], taxonomy_version: str) -> list[dict]`:
- For each publication in scoring_results that has dense_scores:
  - For each (topic_id, score) in dense_scores where score >= 0.3:
    - Create a DynamoDB item dict:
      ```python
      {
          "PK": {"S": f"TOPIC#{topic_id}"},
          "SK": {"S": make_score_sk(score, pub['pmid'])},
          "faculty_uid": {"S": f"cwid_{pub['cwid']}"},
          "score": {"N": str(to_decimal(score))},
          "synopsis": {"S": pub.get('synopsis', '') or ''},
          "impact_score": {"N": str(to_decimal(pub.get('impact_score', 0) or 0))},
          "year": {"N": str(pub.get('pub_year', 0) or 0)},
          "journal": {"S": pub.get('journal', '') or ''},
          "title": {"S": pub.get('title', '') or ''},
          "topic_scores_version": {"S": taxonomy_version},
          "department": {"S": pub.get('department', '') or ''},
      }
      ```
- CRITICAL: Every TOPIC# record MUST include `faculty_uid` attribute so GSI 1 (FacultyTopicsIndex) indexes it (per RESEARCH.md Pitfall 5)
- Return list of all topic record items
- Print: "Built {N} TOPIC# records from {M} publications"

Function `load_topic_records(dynamo_client, table_name: str, records: list[dict])`:
- Call `batch_write(dynamo_client, table_name, records)` with tqdm progress wrapper
- Print: "Loaded {N} TOPIC# records"

**Record Type 2 -- FACULTY# profile records (DB-03):**

Function `build_faculty_records(scoring_results: list[dict], faculty_metadata: dict, taxonomy_version: str) -> list[dict]`:
- Aggregate scored publications per faculty (cwid):
  - For each cwid, collect all topics they scored on and compute the max dense score per topic
  - `top_topics`: list of `{"topic_id": str, "max_score": float}` sorted by max_score descending, top 10
- For each cwid in faculty_metadata:
  - Create a DynamoDB item:
    ```python
    {
        "PK": {"S": f"FACULTY#cwid_{cwid}"},
        "SK": {"S": "PROFILE"},
        "faculty_uid": {"S": f"cwid_{cwid}"},
        "name": {"S": meta['name']},
        "department": {"S": meta['department']},
        "h_index": {"N": str(meta.get('h_index', 0) or 0)},
        "article_count": {"N": str(meta.get('article_count', 0) or 0)},
        "first_author_count": {"N": str(meta.get('first_author_count', 0) or 0)},
        "last_author_count": {"N": str(meta.get('last_author_count', 0) or 0)},
        "top_topics": {"L": [
            {"M": {"topic_id": {"S": t['topic_id']}, "max_score": {"N": str(to_decimal(t['max_score']))}}}
            for t in top_topics_for_cwid
        ]},
        "taxonomy_version": {"S": taxonomy_version},
    }
    ```
- Only include faculty who have at least one scored publication (appeared in scoring_results)
- Print: "Built {N} FACULTY# records"

Function `load_faculty_records(dynamo_client, table_name: str, records: list[dict])`:
- Call `batch_write(dynamo_client, table_name, records)`
- Print: "Loaded {N} FACULTY# records"

**Record Type 3 -- TOOL# score records (DB-04):**

Function `build_tool_records() -> list[dict]`:
- Extract tool data directly from ReciterDB using `TOOL_EXTRACTION_SQL` (defined in utils/sql_queries.py, queries `reciterai_keyword_relevance` table).
- Connect via `get_raw_db_connection()` and execute `TOOL_EXTRACTION_SQL`.
- The SQL returns: pmid, tool_id (keyword column), relevance_score_raw (int 0-100), cwid.
- Transform each result into a TOOL# DynamoDB item:
  ```python
  normalized_score = row['relevance_score_raw'] / 100.0  # Convert 0-100 int to 0.0-1.0 float
  {
      "PK": {"S": f"TOOL#{row['tool_id']}"},
      "SK": {"S": make_score_sk(normalized_score, row['pmid'])},
      "faculty_uid": {"S": f"cwid_{row['cwid']}"},
      "score": {"N": str(to_decimal(normalized_score))},
      "topic_scores_version": {"S": "keyword_relevance_v1"},
  }
  ```
- CRITICAL: Include `faculty_uid` on every TOOL# record for GSI 1 (Pitfall 5).
- **HARD ASSERTION (Blocker fix):** After extracting tool data, assert `len(tool_records) > 0`. If the assertion fails, raise an error: `"TOOL# records: 0 rows returned from reciterai_keyword_relevance for publications. This means DB-04 will not be delivered. Check: (1) Does reciterai_keyword_relevance have entity_type='publication' rows? (2) Are the join columns correct? Run utils/env_check.py to diagnose."` Do NOT silently skip or log-and-continue.
- Print: "Built {N} TOOL# records from {M} unique tools"

Function `load_tool_records(dynamo_client, table_name: str, records: list[dict])`:
- Call `batch_write(dynamo_client, table_name, records)` with tqdm progress wrapper
- Print: "Loaded {N} TOOL# records"
